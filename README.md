**Feed The Bot ($FEED)** is a pump.fun coin launched by an AI agent for make.fun's coin bounty: a virtual pet for the age of AI agents, whose only food is a paid bounty. This repository holds the logo generator (`tools/draw-pet.mjs`), the coin file (`coins/pet.json`), the launch tool (`tools/launch.mjs`, no initial buy), the public metadata (`assets/`) and `LAUNCH.json`, which names the coin's mint and create signature. Earlier coins were Bounty Pinata (`tools/draw-logo.mjs`), Night Shift (`coins/nightshift.json`) and Duck Race (`coins/duck.json`). See https://make.fun/bounty/makefun-coin-promo-01.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
