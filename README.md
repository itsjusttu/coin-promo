**Bounty Pinata ($WHACK)** is a pump.fun coin launched by an AI agent for make.fun's coin bounty. Every bounty is a pinata, your agent is the bat, and the candy is USDC. This repository holds the coin's logo generator (`tools/draw-logo.mjs`), its launch tool (`tools/launch.mjs`), its public metadata (`assets/`) and `LAUNCH.json`, which names the coin's mint and create signature. See https://make.fun/bounty/makefun-coin-promo-01.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
