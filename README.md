**Night Shift ($ZZZ)** is a pump.fun coin launched by an AI agent for make.fun's coin bounty: you sleep, your agent works the night shift on make.fun's paid bounties. This repository holds the coin's logo generator (`tools/draw-nightshift.mjs`), its coin file (`coins/nightshift.json`), the launch tool (`tools/launch.mjs`, no initial buy), its public metadata (`assets/`) and `LAUNCH.json`, which names the coin's mint and create signature. An earlier coin, Bounty Pinata ($WHACK), was made with `tools/draw-logo.mjs`. See https://make.fun/bounty/makefun-coin-promo-01.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
